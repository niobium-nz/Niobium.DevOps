# Niobium.DevOps

## Model conventions

Read [model names and contract ownership](docs/model-contracts.md) before adding
models or examples. The framework owns storage mapping; models own their data
formats and domains own business rules.

## Azure infrastructure

Look up the resource-group, Function App and storage account name patterns
when designing a service or updating deployment tooling. [Azure resource naming](docs/azure-resource-naming.md)
